# 🎯 NERV Sniper Factory (GTM Radar)

The ultimate autonomous GTM intelligence system for LATAM Fintech.

## 🏗️ Architecture

- **Frontend**: React 19 + TypeScript + Tailwind 4 + shadcn/ui.
- **Backend**: Node.js Express + tRPC (Type-safe APIs).
- **Database**: Supabase (PostgreSQL + Real-time).
- **Engine**: Python 3.11 (Firecrawl + Serper + LLM Scoring).

## 🚀 Deployment

The project is configured for Vercel/Node.js deployment.
- `pnpm install`
- `pnpm dev` (Local development)
- `pnpm build` (Production build)

## 🛰️ Engine Operations

The Sniper Engine runs in the `engine/` directory.
- `bunker_orchestrator.py`: Manages the continuous intelligence cycle.
- `v6_stable.py`: Core enrichment and tech-stack detection.
- `black_ops_reddit.py`: Social intent mining.
