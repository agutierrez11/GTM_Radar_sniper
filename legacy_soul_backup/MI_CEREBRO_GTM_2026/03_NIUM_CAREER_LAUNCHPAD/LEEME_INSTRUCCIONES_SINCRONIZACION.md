# 🗺️ Guía de Sincronización: VM 🔄 Laptop

Toda tu inteligencia en la carpeta `MI_CEREBRO_GTM_2026` está protegida y lista para usarse en cualquier dispositivo.

## 🌟 1. Bóveda Maestra (01_BOVEDA_MAESTRA_3700_EMPRESAS)
Esta es la que hemos estado trabajando duro.
- **En la VM:** Se sincroniza automáticamente con GitHub cada vez que el bot de Telegram agrega una empresa o tú haces un cambio.
- **En tu Laptop:**
  1. Descarga el repositorio de GitHub: `https://github.com/agutierrez11/MI_CAPITAL_GTM_2026.git`
  2. Abre esa carpeta en Obsidian.
  3. Instala el plugin **Obsidian Git**.
  4. Configura el plugin para que haga **Pull al iniciar** (para bajar lo que el bot o yo hayamos hecho en la VM) y **Push cada 5 minutos**.

## 🛡️ 2. Proyecto Sumsub (02_PROYECTO_SUMSUB_QUIRURGICO)
- **Status:** Es una herramienta táctica. Puedes subirla a un repo nuevo de GitHub si quieres tenerla también en la laptop, o simplemente copiarla por USB/Nube.
- **Recomendación:** Úsala principalmente en la VM durante la entrevista para proyectar el grafo si es necesario, ya que aquí tiene todo el "poder de cómputo" del bot conectado.
