# Instrucciones de la Bóveda Ajustada

Esta bóveda ha sido optimizada para enfocarse exclusivamente en las industrias core de **Sumsub**.

## Cambios Realizados:
1. **Filtrado de Industrias:** Se han consolidado las industrias anteriores en las categorías oficiales de Sumsub:
   - **Financial services** (Incluye: Regtech, Crédito, BFM, Open, PFM, Crowdfunding, Insurtech)
   - **Payment** (Anteriormente: Paytech)
   - **Trading** (Anteriormente: WealthTech)
   - **Crypto** (Anteriormente: Activos)
   - **Neobancos** (Se mantiene)
   - **iGaming, Mobility, Marketplaces** (Nuevas categorías listas para usar)

2. **Navegabilidad:**
   - Si buscas un **País**, verás las industrias core presentes y las empresas asociadas.
   - Si buscas una **Industria**, verás los productos sugeridos y las empresas que pertenecen a ella.
   - Cada **Empresa** tiene enlaces directos a su País, Industria y Oportunidad (Producto).

3. **Estructura:** Se mantienen las 7 carpetas originales, pero con el contenido interno actualizado y mapeado correctamente.

## Cómo usar:
Simplemente abre esta carpeta en Obsidian. El archivo `MapaMaestroFintechLatam.md` sigue siendo tu punto de entrada principal.
