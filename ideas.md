# 🎯 NERV Sniper GTM: Exploración de Diseño

## Contexto Estratégico
**NERV Sniper GTM** es una fábrica de liquidación de cuentas. No es un CRM genérico, sino una infraestructura crítica para equipos de GTM que transforman leads en "diamantes" (oportunidades de alto valor) mediante inteligencia pre-digerida.

El diseño debe reflejar: **precisión quirúrgica**, **inteligencia competitiva**, **velocidad de ejecución** y **claridad operativa**.

---

## Idea 1: "Tactical Command Center" (Probabilidad: 0.08)
**Movimiento de Diseño:** Cyberpunk militar + Minimalism operativo

### Core Principles
1. **Precision Over Decoration:** Cada píxel tiene propósito táctico. Nada es ornamental.
2. **Real-Time Dominance:** El dashboard es una "sala de guerra" donde se ven todas las señales simultáneamente.
3. **Hierarchy by Urgency:** Lo más crítico (pain points, kill-shots) está siempre visible.
4. **Scannable at Glance:** Un vendedor debe entender la situación en 3 segundos.

### Color Philosophy
- **Primary:** Azul oscuro profundo (`#0A1428`) con acentos de cian neon (`#00D9FF`)
- **Reasoning:** Transmite control, tecnología avanzada, ambiente de "sala de guerra"
- **Accents:** Rojo para alertas críticas, verde para oportunidades confirmadas
- **Background:** Casi negro con grid sutil (efecto de radar)

### Layout Paradigm
- **Asymmetric Grid:** Paneles de tamaños variables según importancia
- **Left Sidebar:** Filtros y navegación táctica (país, segmento, tier)
- **Center Canvas:** Grafo interactivo de empresas (nodos conectados por relaciones)
- **Right Panel:** Battle Card expandible (dolor → solución → kill-shot)
- **Top Ribbon:** Métricas en tiempo real (empresas cazadas, diamantes refinados, cierres)

### Signature Elements
1. **Radar Grid Background:** Líneas sutiles que evocan un sistema de escaneo
2. **Pulsing Nodes:** Los nodos en el grafo pulsan según "temperatura" (urgencia)
3. **Glow Effects:** Bordes luminosos en elementos interactivos

### Interaction Philosophy
- **Hover = Reveal:** Al pasar sobre un nodo, se revelan sus pain points y conexiones
- **Click = Expand:** Clic en empresa abre Battle Card con kill-shot
- **Drag = Explore:** Arrastra el grafo para explorar relaciones

### Animation
- **Entrance:** Nodos aparecen con efecto de "scan" (línea que los dibuja)
- **Transitions:** Movimientos rápidos (200-300ms) que evocan precisión militar
- **Micro-interactions:** Glow sutil al hover, pulso al cargar datos

### Typography System
- **Display:** IBM Plex Mono Bold (fuente monoespaciada para datos)
- **Body:** Inter Regular (legibilidad en datos tabulares)
- **Hierarchy:** Mono para números/métricas, Inter para contexto

## Idea 2: "Obsidian Intelligence Graph" (Probabilidad: 0.07)
**Movimiento de Diseño:** Knowledge Management + Neomorphism

### Core Principles
1. **Interconnected Thinking:** Las relaciones son más importantes que los nodos individuales
2. **Emergent Patterns:** El usuario descubre oportunidades al explorar conexiones
3. **Soft Minimalism:** Diseño limpio pero con profundidad táctil
4. **Context Richness:** Cada elemento tiene múltiples capas de información

### Color Philosophy
- **Primary:** Gris cálido (`#E8E6E1`) con acentos violeta suave (`#8B7BA8`)
- **Reasoning:** Evoca cuadernos inteligentes, ambiente de "pensamiento profundo"
- **Secondary:** Tonos tierra (ocre, siena) para categorías
- **Background:** Blanco roto con textura sutil

### Layout Paradigm
- **Center-First Graph:** El grafo ocupa el 70% del espacio
- **Floating Cards:** Información contextual en tarjetas flotantes alrededor del grafo
- **Left Sidebar Minimal:** Solo filtros esenciales
- **Right Sidebar:** Timeline de actividad y notas

### Signature Elements
1. **Soft Shadows:** Neomorphism suave (sombras internas y externas)
2. **Connection Lines:** Líneas suaves que muestran relaciones (Bézier curves)
3. **Color-Coded Categories:** Cada tipo de nodo (empresa, pain point, solución) tiene color distintivo

### Interaction Philosophy
- **Explore = Learn:** El usuario navega el grafo como si explorara un jardín
- **Click = Contextualize:** Clic revela información relacionada
- **Zoom = Focus:** Zoom in/out para cambiar nivel de detalle

### Animation
- **Entrance:** Nodos aparecen con efecto de "fade + scale" suave
- **Transitions:** Movimientos fluidos (400-500ms) que evocan reflexión
- **Micro-interactions:** Sombra dinámica al hover, expansión suave

### Typography System
- **Display:** Playfair Display (serif elegante para títulos)
- **Body:** Lato Regular (humanista, legible)
- **Hierarchy:** Serif para contexto estratégico, sans-serif para datos

## Idea 3: "Velocity Dashboard" (Probabilidad: 0.06)
**Movimiento de Diseño:** Sports Analytics + Data Visualization

### Core Principles
1. **Action-Oriented:** Cada elemento invita a una acción específica
2. **Performance Metrics:** El dashboard es un "marcador" de la cacería
3. **Progressive Disclosure:** Información se revela según interés del usuario
4. **Momentum Visualization:** Se ve el "flujo" de oportunidades

### Color Philosophy
- **Primary:** Naranja energético (`#FF6B35`) con acentos de azul marino (`#004E89`)
- **Reasoning:** Transmite energía, urgencia, movimiento (como un marcador deportivo)
- **Secondary:** Verde para "ganadas", rojo para "perdidas"
- **Background:** Blanco limpio con accent bars

### Layout Paradigm
- **Horizontal Flow:** Las empresas se visualizan como un "flujo" de izquierda (Hunting) a derecha (Liquidation)
- **Top Metrics:** KPIs grandes y legibles
- **Middle Canvas:** Tarjetas de empresas en pipeline visual
- **Bottom Timeline:** Historial de actividad

### Signature Elements
1. **Progress Bars:** Visualización del progreso en cada fase (Hunting → Refinery → Liquidation)
2. **Score Badges:** Cada empresa tiene un "score" visual (1-10 diamantes)
3. **Momentum Arrows:** Flechas que indican dirección del movimiento

### Interaction Philosophy
- **Drag to Move:** Arrastra empresas entre fases
- **Quick Stats:** Hover revela métricas clave
- **One-Click Actions:** Botones grandes para acciones comunes

### Animation
- **Entrance:** Tarjetas deslizantes desde la izquierda
- **Transitions:** Movimientos rápidos y directos (200ms)
- **Micro-interactions:** Bounce sutil al soltar, color flash al completar acción

### Typography System
- **Display:** Montserrat Bold (geométrico, energético)
- **Body:** Open Sans Regular (amigable, legible)
- **Hierarchy:** Bold para métricas, regular para contexto

---

## Decisión Final: **"Tactical Command Center"** ✅

### Por Qué
1. **Alineación Estratégica:** Refleja la naturaleza militar de la estrategia (Clausewitz, Sun Tzu)
2. **Velocidad Operativa:** El vendedor ve todo lo que necesita en 3 segundos
3. **Diferenciación:** No es otro dashboard "bonito", es un **arma táctico**
4. **Escalabilidad Visual:** Funciona bien con 10 o 1000 empresas sin perder claridad

### Filosofía de Diseño Elegida
- **Cyberpunk Militar Minimalista:** Precisión, control, inteligencia en tiempo real
- **Color:** Azul oscuro + cian neon + rojo/verde para alertas
- **Tipografía:** IBM Plex Mono (datos) + Inter (contexto)
- **Interacción:** Hover revela, clic expande, drag explora
- **Animación:** Rápida, precisa, sin distracción
